# ALGAIR Website

A modern, responsive website for ALGAIR - Smart Algae-Based Exhaust Treatment System.

## 🚀 Quick Start

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Extract the project folder
2. Navigate to the project directory:
   ```bash
   cd algair-website
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173`

### Build for Production

```bash
npm run build
```

The optimized production build will be in the `dist` folder.

### Preview Production Build

```bash
npm run preview
```

## 🎨 Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile
- **Smooth Navigation**: Single-page application with instant section switching
- **Visual Diagrams**: SVG illustrations for processes and concepts
- **Clean UI**: Modern, minimalist design with focus on content
- **Performance**: Optimized with Vite for fast load times

## 🌍 Navigation

The website includes 7 main sections:

1. **ALGAIR** - Product introduction and overview
2. **Problem** - The environmental challenge ALGAIR addresses
3. **Solution** - How ALGAIR solves the problem
4. **How It Works** - The treatment process explained
5. **Technology** - Inside the system and the role of algae
6. **Features** - Key features and benefits
7. **Future** - Development roadmap and applications
